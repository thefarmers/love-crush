# Love Crush

**เกมจับคู่ผลไม้ (Match-3) ที่คุณเอาไปทำเป็นของขวัญให้คนที่คุณรักได้** — fork ไป ใส่ชื่อ ข้อความ และรูปของคุณสองคนในไฟล์ config ไฟล์เดียว แล้วเอาขึ้นเว็บฟรี
พอหัวใจหมด คนเล่นต้อง **พูดบอกรักออกมาดังๆ** เพื่อเติมหัวใจ

[English README](README.md)

- 🍓 1,000 ด่านสร้างอัตโนมัติ ความยากปรับด้วยบอท AI
- 🎨 กราฟิกวาดด้วยโค้ดทั้งหมด (ไม่มีไฟล์รูป) ผลไม้ 6 ชนิด ธีมชมพูอ่อน-งาช้าง
- 🎵 เพลง 3 เพลงแต่งและสังเคราะห์ในโค้ด (คาลิมบา, ฮาร์ปวอลทซ์, lo-fi เปียโน) หรือใช้เพลงของคุณเอง
- 💌 กลไก "บอกรัก" ด้วยเสียง (Web Speech API + มิเตอร์ความดัง), การ์ดความรัก และคูปองใช้ได้จริง
- 📱 เว็บแอปเน้นมือถือ เล่นออฟไลน์ได้ ไม่มี backend ไม่มีการเก็บข้อมูล
- ✅ เทสต์ 100+ ข้อ, TypeScript, ไม่มี dependency ตอนรัน

## ทำให้เป็นของคุณใน 5 นาที

1. **Fork** repo นี้ แล้ว clone ลงเครื่อง
2. แก้ **`src/config/personal.ts`** ไฟล์เดียว:

   | ค่า | ใช้ทำอะไร |
   | --- | --- |
   | `locale` | ภาษาในเกม: `'th'` หรือ `'en'` (เพิ่มภาษาได้ใน `src/i18n/`) |
   | `partnerName`, `myName` | คำเรียกคนเล่นและตัวคุณ (ค่าเริ่มต้น "ตัวเอง" / "เค้า") |
   | `loveKeywords` | คำที่นับว่า "บอกรัก" |
   | `loveCards` | การ์ดที่เปิดได้ทุกครั้งที่บอกรักสำเร็จ — ข้อความ คูปอง หรือรูปคู่ |
   | `secretPhrases` | ประโยคลับ พูดแล้วได้ไข่มุกสายรุ้งฟรี |
   | `winMessages`, `loseMessages` | ข้อความตอนชนะ/แพ้ |
   | `specialLevels` | ข้อความพิเศษบนด่านที่มีความหมาย เช่น ด่าน 14 |
   | `bgm` | เพลงของคุณเอง เช่น `'music/our-song.mp3'` |
   | `share` | หัวข้อ/คำอธิบายตอนแชร์ลิงก์ และข้อความบนรูปตัวอย่าง (วาดรูปใหม่ด้วย `npm run og`) |

3. ใส่รูปไว้ที่ `public/photos/` และเพลงไว้ที่ `public/music/`
4. รันเกม (ทำใน Terminal ที่โฟลเดอร์โปรเจกต์):

   ```bash
   npm install
   npm run dev
   ```

   แล้วเปิด `http://localhost:5173` ใน Chrome (หยุดด้วย `Ctrl + C`)

5. รัน `npm test` — จะตรวจ config ของคุณให้ด้วยว่าใส่ถูกไหม

> **เรื่องความเป็นส่วนตัว:** repo ที่ fork จาก repo สาธารณะจะเป็นสาธารณะ และเว็บ GitHub Pages ก็เปิดให้ทุกคนที่มีลิงก์เข้าดูได้
> ทุกอย่างที่ใส่ใน `personal.ts`, `public/photos/`, `public/music/` จะถูกเห็นได้ ถ้าอยากเก็บโค้ดเป็นส่วนตัวให้ใช้ *Use this template* → สร้าง repo แบบ private
> และใส่เฉพาะรูปที่โอเคถ้าคนอื่นเห็น

## เอาขึ้นเว็บ (ฟรี มี https ซึ่งจำเป็นสำหรับไมค์)

**GitHub Pages:** push ขึ้น branch `main` แล้วไปที่ repo → *Settings → Pages → Source: GitHub Actions*
workflow ที่ให้มาจะรันเทสต์ build และเผยแพร่ไปที่ `https://<ชื่อคุณ>.github.io/<ชื่อ repo>/` ให้อัตโนมัติ

**ที่อื่น:** `npm run build` แล้วอัปโหลดโฟลเดอร์ `dist/` ขึ้นโฮสต์ static ที่ไหนก็ได้ (เช่น ลากไปวางที่ [Netlify Drop](https://app.netlify.com/drop))

บนมือถือให้กด *แชร์ → เพิ่มไปยังหน้าจอโฮม* จะเปิดเต็มจอเหมือนแอป เล่นออฟไลน์ได้ และเซฟปลอดภัยกว่า

## เล่นยังไง

- เรียง 3 ลูก · 4 ลูก = **ผลไม้แสงวิ่ง** (เก็บทั้งแถว/คอลัมน์) · ตัว L/T = **ผลไม้วงทอง** (ระเบิด 3×3) · 5 ลูก = **ไข่มุกสายรุ้ง** · สี่เหลี่ยม 2×2 = **คิวปิดมีปีก**
- สลับผลไม้พิเศษ 2 ลูกเข้าหากันได้คอมโบ (กากบาท, สามแถวสามคอลัมน์, ระเบิด 5×5, พายุไข่มุก, ล้างกระดาน)
- เป้าหมายสลับทุกไม่กี่ด่าน: เยลลี่ · เก็บผลไม้ · พาแหวน/จดหมายลงขอบ · กล่องของขวัญ · ช็อกโกแลต · คะแนน · บอสจับเวลา
- ความยากเป็นฟันปลาในทุก 10 ด่าน และค่อยๆ เพิ่มขึ้นตลอด ~250 ด่าน ช่วงแรกได้ 3 ดาวง่าย ด่านหลังๆ ค่อยท้าทาย

| ช่วงด่าน | win rate ของบอท | ชนะแล้วได้ 3 ดาว |
| --- | --- | --- |
| 1–30 | ~90–98% | ~70% |
| 101–200 | ~76% | ~47% |
| 300 ขึ้นไป | ~67% | ~30% |

อยากให้ง่ายหรือยากขึ้น: ปรับ `targetWinRate` / `starQuantiles` ใน `src/levels/difficulty.ts` แล้วรัน `npm run calibrate`

## โครงสร้างโค้ด

ดู [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) และวิธีร่วมพัฒนาที่ [CONTRIBUTING.md](CONTRIBUTING.md)

| โฟลเดอร์ | |
| --- | --- |
| `src/core` | เอนจินเกมล้วน (ไม่แตะ DOM) |
| `src/levels` | สร้างด่าน, รูปทรงกระดาน, กราฟความยาก, `calibration.json` |

| `src/ui` | หน้าจอต่างๆ |
| `src/i18n` | ข้อความทั้งหมดในเกม (ไทย, อังกฤษ) |
| `src/config` | `personal.ts` ← แก้ตรงนี้ |
